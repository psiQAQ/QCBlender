## 诊断与范围

初次候选在原构型身份检查失败，修复后重建为本页候选；旧候选和失败日志保留。桌面进程无法读取受限环境生成的部分 Dataset 时，在独立桌面配置重新生成同输入工程，没有修改 ACL。冷读脚本首次把原生 tuple 与 JSON list 直接比较而失败，统一 JSON 表示后复验通过，原失败收据保留。Properties 中 Ctrl+Shift+Z 未改变状态；实际通过的是 Edit → Redo。

原子身份、有效域和性能中的合成数据只提供工程证据。现有 P04/C10 没有真实逐步部分电荷输入，IRC 逐步电荷暂缓；DI/ASM、ESM 等新增科学分析仅列为研究候选。完整 VTK 构建、超过 512 原子的性能、独立科研接受及远端发布均未在本批执行。
