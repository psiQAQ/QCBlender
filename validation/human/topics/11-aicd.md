## 理解张量、Aniso 与磁场

> AICD 原始张量 `T` 描述给定位置的电流密度对外磁场的线性响应。这里九分量按“行＝电流 x/y/z，列＝磁场 x/y/z”保存。

> Aniso 是张量对称无迹部分的各向异性标量：`sqrt(3/2) × ||(T+Tᵀ)/2 − tr(T)I/3||F`。它不是 NICS，也不是电流向量的模长。

导入后，黄色等值面显示 Aniso，箭头显示 `J = T B̂`，其中 `B̂` 是归一化后的磁场方向。张量与单位场响应均保留响应原子单位，即电流密度原子单位／磁场原子单位。输入 `(0,0,3)` 和 `(0,0,1)` 得到相同响应；改为 `(0,0,-1)` 会反转箭头，Aniso 不变。蓝色箭头及文字标明单位磁场。

磁场分量使用**原始生成坐标系**。整体移动或旋转 AICD 对象会带着分子、等值面和磁场标记一起移动，不会重新计算源张量。箭头长度缩放只改变显示，数值读值及导出不乘该缩放。

## 比较同源苯的全电子与 π 结果

本例为 Gaussian 16 C.01、RB3LYP/6-31G(d)、6D/7F、CSGT、SCF=Tight、UltraFine，固定 XY 平面的苯构型。全电子与 π 是两次独立生成的张量转储；π 选取同一波函数的占据轨道 `17,20,21`，共 6 个电子。π 归属已有本例的波函数分析依据，不能将这些轨道号套用到别的计算。

<a id="step-01"></a>
### 1. 导入生成朝向的静态分子

按[准备新工程](../SOP.md#new-scene)进入物体模式，通过 **N 侧栏 → QCBlender → 导入与导出 → 导入 Gaussian / Cube / XYZ** 导入：

`shared/data/local/scientific-displays/aicd-benzene/all/all.fchk`

选中生成的 12 原子静态分子。其原子顺序与坐标应符合日志中的 Standard orientation；不要使用另行对齐或优化后的坐标。轨迹、优化及 IRC 动态对象不能作为参考。

<a id="step-02"></a>
### 2. 导入全电子张量并指定等值值

打开 **N 侧栏 → 导入与导出 → 导入外部结果 → 空间场分析 → AICD 张量**，填写：

| 参数 | 本例输入 |
| --- | --- |
| AICD 来源 JSON | `shared/data/local/scientific-displays/aicd-benzene/all/source.json` |
| Aniso 等值值 | `0.05`，响应原子单位 |
| AICD 网格间距 | `0.25 Å` |
| AICD 边界外扩 | `2.5 Å` |
| 内存预算 | `512 MiB` |

等值值必须明确填写，初始 `0` 不会自动套用其他程序的值。`0.05` 是本例的显示选择，不是适用于所有分子的芳香性阈值。确认后等待后台导入完成，生成独立的 `QC AICD all` 对象；原分子保留。

在新对象的 **对象属性 → QCBlender → AICD 来源与响应** 查看全电子贡献、程序版本、`240570` 个原始点和最多 `1000` 个显示箭头。等值面及箭头应围绕同一个苯环；需要清楚观察时可隐藏原分子副本，并关闭视口叠加层。输入哈希、计算段、轨道号或静态构型不匹配时，先核对原始材料，不要编辑日志来绕过检查。

<a id="step-03"></a>
### 3. 改变磁场方向和箭头数量

点击 **AICD 显示设置**。将磁场方向设为 `(0,0,-3)`、箭头数上限设为 `250`，其他参数保留。确认后，磁场归一化为 `(0,0,-1)`，箭头反向并减少，等值面保持不变。零磁场会被拒绝。

**显示 Aniso 等值面**、**显示电流响应箭头**及**显示参考原子**分别控制三个部分；颜色和不透明度只改变外观。取消弹窗保留原设置，确认后的修改可通过 **编辑 → 撤销 / 重做**恢复。比较不同贡献时，应使用相同的等值值、网格、磁场及箭头缩放，并保留这些参数。

<a id="step-04"></a>
### 4. 读取原始点并导出全部数值

点击 **读取 AICD 原始采样点**，输入从零开始的索引 `12345`。本例全电子数据应显示块 `29`、局部点 `73`，坐标约为 `(-0.804191, 2.2008, -0.105296) Å`，积分权重 `0.00222433`，Aniso `0.0138448`。在上一步的负 Z 单位场下，`J = (-0.00825361, -0.0274461, -0.000248982)`；下面三行保留完整九分量张量。

截图保存为 `human/screenshots/AICD01-source-response.jpg`。

![真实全电子 AICD 的来源、250 个箭头与原始点 12345 读值](../screenshots/AICD01-source-response.jpg)

点击 **导出科学数据**，数据类型选择 **AICD**，按[公共导出步骤](../SOP.md#export)保存到 `work/human/AICD01-export/`。`aicd_samples.csv` 包含全部 `240570` 个原始点，而不是显示的 250 个箭头：原始块及点号、bohr/Å 坐标、积分权重、九分量、Aniso 和当前单位场下的 J。随附元数据保留输入身份、轨道声明、生成坐标系及重映射参数。

<a id="step-05"></a>
### 5. 导入 π 贡献并保存工程

重新选中第 1 步的静态分子，重复第 2 步，来源 JSON 改为：

`shared/data/local/scientific-displays/aicd-benzene/pi/source.json`

保留相同的 `0.05`、`0.25 Å`、`2.5 Å` 和 `512 MiB`。生成 `QC AICD pi` 后，来源面板应显示 π、轨道 `17,20,21`、`240570` 个原始点，以及“轨道号已核对；π/σ 归属由使用者声明”。本例归属依据存于来源声明；程序不会仅凭“pi”文件名判断轨道性质。

可将两个 **AICD 根对象**移到左右并列位置；不要单独移动其子对象。本例相同等值值下，全电子表面更接近六边形环，π 表面更接近连续圆环。它们来自不同的张量数据，不通过开关从全电子数据中伪造 π 分解。环流的科学解读仍需结合计算条件及独立分析。

按[保存与重开](../SOP.md#save)保存为 `work/human/AICD01-benzene.blend`，保留同名 `.qcdata/`。重开后查看两个对象的贡献身份、等值值、磁场、箭头数及最后读取的点；再次读一个点确认数据可用。移动工程时将 `.blend` 与 `.qcdata/` 成套移动。

## 准备自己的来源声明

首版接受 Gaussian CSGT 的 `Gitterpunkte:`、`Gewichtungsfaktoren:`、`Stromdichtetensor, II=1/2/3` 原始文本，每块保留相同的点数和从 1 开始的局部编号。原始坐标为 bohr，II 按列组成张量。缺块、重复段、非有限值及负积分权重会被拒绝。

保留同次计算的输入、完整日志及张量转储，将它们放在同一个来源声明目录内。输入须为默认 Å 单位的显式笛卡尔坐标；程序核对日志的 Input orientation、输入电荷/多重度及 route，再用生成时 Standard orientation 匹配所选静态分子。当前限定固定构型的闭壳层单重态，不支持从 checkpoint 隐式读取构型、Z-matrix 或非平面 π/σ 归属。日志必须正常结束并明确写出该转储文件，所选计算段不得包含变化构型。

下面是**结构示例**；尖括号内容必须替换为自己的真实文件哈希，不能直接作为输入：

```json
{
  "format": "qcblender.aicd.source.v1",
  "coordinate_unit": "bohr",
  "response_unit": "au_current_density_per_au_field",
  "job_index": 0,
  "component": "all",
  "orbitals": [],
  "orbital_assignment_evidence": "",
  "files": {
    "tensor": {"path": "AICD.txt", "sha256": "<张量文件 SHA-256>"},
    "log": {"path": "all.log", "sha256": "<日志 SHA-256>"},
    "input": {"path": "all.gjf", "sha256": "<输入 SHA-256>"}
  }
}
```

在文件目录用 PowerShell 的 `Get-FileHash -Algorithm SHA256 -LiteralPath .\AICD.txt` 等命令取得哈希，填写小写十六进制值。三个 `path` 必须相对于声明目录，不能跳出该目录。`job_index` 从 0 开始，选择日志中实际生成转储的计算段。

`component` 可为 `all`、`pi`、`sigma`、`selected` 或 `unknown`。全电子要求 `IOp(10/93=1)` 且无选择轨道；已选择贡献要求 `IOp(10/93=2)`，`orbitals` 与日志 `CSGT: Occupy MOs` 完全一致。π/σ 还需填写同源波函数、轨道分析方法和证据定位；没有归属依据时保留 `selected` 或 `unknown`。程序能核对轨道号与日志，不能代替轨道性质的科学判定。

## 理解网格与内存限制

规则网格只用于显示。程序先在原始点计算 Aniso，再将该标量和九分量张量分别映射到最近四个有限网格节点，用 `1/max(d, 10⁻⁸ Å)` 归一化；并列距离按网格编号确定次序。原始 Gaussian 积分权重被保存，但不参与显示插值。网格外原始点仍向有限网格的最近节点贡献，不将坐标截到边界；无贡献节点保留无效掩码，等值面不填洞或外推。

网格从原子包围盒向各侧扩展指定距离。较小间距增加内存与计算量，也会改变有效域和局部数值。本例 `0.25 Å` 与 `0.125 Å` 的独立算法对照均通过，但两种间距之间并未收敛到相同数值；不能把网格显示当作积分守恒的计算结果。原始点读值和 CSV 不受网格间距或箭头抽样影响。

默认 `512 MiB` 预算包含原始数组、网格九分量缓存及分块工作空间。超限时导入会明确失败，不会自动放粗网格。可增大间距、减小边界外扩，或在确认本机资源后提高预算。等值值需大于零并小于有效网格最大值；没有表面时先检查该范围和输入身份。
