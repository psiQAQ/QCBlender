# Public tutorial samples

Current dataset: Gaussian-v1. Owned calculation data: CC BY 4.0; attribution QCBlender contributors. P01/P03/P05 are optimized structures at the original methods/bases; P02 is an owned two-job water optimization/frequency/NBO output. P04 contains a first-order saddle and a complete bidirectional geomeTRIC 1.1.1 IRC driven by real Gaussian energies and gradients, with Gaussian endpoint frequency checks; the conventional single-job Gaussian IRC attempts were not accepted as complete. P05 fragments retain their geometries in the optimized complex. P06 contains coordinate-only XYZ derivatives. Native FCHK files are produced by Gaussian formchk.

The independent Gaussian-native-IRC-v1 supplement contains 53 RHF/STO-3G frames from 52 native Gaussian GS2 segments and their TS. Continuations use the documented Downhill entry point; all new coordinates are generated by Gaussian. Both endpoints have positive frequencies and maximum gradients below 10^-6 Hartree/Bohr. This is a segmented workflow, not a claim that the conventional single-job early termination has been repaired. Its manifest records all inputs, logs, wavefunctions, source links and derived Mayer results under CC BY 4.0. The original Gaussian-v1 files and v3 package are unchanged.

Gaussian 16 Revision C.01 is the wavefunction producer. Multiwfn 2026.9.20 produces IGMH/IRI, ESP/AIM and NOCV analyses. Cite Tian Lu, Feiwu Chen, J. Comput. Chem. 33, 580 (2012), DOI:10.1002/jcc.22885; Tian Lu, J. Chem. Phys. 161, 082503 (2024), DOI:10.1063/5.0216272.

Gaussian-v1 IRC integration and endpoint relaxation use geomeTRIC 1.1.1; cite L.-P. Wang and C. Song, J. Chem. Phys. 144, 214108 (2016), DOI:10.1063/1.4952956.

NOCV energies use the actual complex KS reconstruction and retain the Multiwfn approximation; they are not evaluated using F_TS. No basis-set or scientific grid-convergence claim is made. QCBlender display grids default to 0.2 angstrom; externally generated analysis grids are recorded separately in the current manifest. Original program outputs retain their scientific values; public copies omit machine execution details.

Legacy-v2 inputs and their frozen manifest remain historical data. Their previous scientific and GUI evidence does not qualify this dataset. The old restricted P02 input is not included.
