# Gaussian 原生 GS2 分段双向路径

本补充数据包含 H₂O₂ 在 **RHF/STO-3G** 下的 **53 帧**：负二面角端点到 TS，再到正二面角端点；**第 27 帧为 TS**。52 个新接受点分别来自 Gaussian 16 Revision C.01 的 52 段原生 GS2 积分。全部波函数、每段输入和日志、端点频率、能量、XYZ 及 318 项 Mayer 原子对记录一并保留。

这是独立补充数据。默认教程仍使用原有 Gaussian-v1 的 69 帧路径及 v3 包；其文件和身份不变。

## 路径如何得到

常规单作业 GS2 在平坦峰顶附近会提前报告 `PES minimum`；本批复现的一步停点仍有虚频，不能据此判为到达极小点。这里两侧首段分别使用 `Forward`、`Reverse`，后续段使用官方 `Downhill` 入口，从上一接受点的检查点继续。每段采用 `CalcAll,GS2,VeryTight,MaxPoints=1`，SCF 使用 `Conver=12,MaxCycle=150`，保持电荷 0、单重态及 `NoSymm`。

调度程序选择下一段的步长并核对结果；每段的新坐标和积分均由 Gaussian 生成。实际步长依次使用 0.05、0.02、0.01 和 0.005 Bohr；最后一种由 `StepSize=5` 与已记录的 `IOp(1/45=3004)` 设置。起点到终点采用同一 TS 的原始笛卡尔坐标系，未单独修改 FCHK 核坐标。

每段的局部第 0 点是已有边界构型，第 1 点是新接受点；边界只计一次。清单保存 `parent_step`、`source_segment` 和 `local_accepted_point`，每份 FCHK 本身也含该段的起点、接受坐标、梯度和反应坐标。全局有符号反应坐标由各段 Gaussian 给出的局部质权弧长累加，单位为 √amu·Bohr。

两端直接在最后接受构型上计算频率，未以端点优化轨迹补足 IRC。最大梯度均小于 10⁻⁶ Hartree/Bohr，六个频率均为正。TS 有一个 −48.1468 cm⁻¹ 的扭转虚频。原生单作业的早停限制仍然存在；本数据的执行身份是**原生积分分段续算**。
