# 当前安装材料

安装文件为本目录的 `qcblender-0.1.0.zip`，适用 Windows x64 / Blender 5.1.1。安装步骤见 [人工 SOP](../../human/SOP.md#install)。

这是已公开并验证的 0.1.0 Alpha Preview 安装包，与 [v0.1.0 Release](https://github.com/psiQAQ/QCBlender/releases/tag/v0.1.0) 附件字节一致。完整教程作为单独 ZIP 分发，不重复包含安装包。当前包身份与日常 Blender 已安装版本分别记录在 [current-install.json](../../agent/current-install.json)。

在 Blender 的 **Edit → Preferences → Get Extensions → 菜单 → Install from Disk** 选择此 ZIP，安装并启用 QCBlender。
