# 子模块主干更新与 QCBlender 维护

批准日期：2026-10-11。开始基线：413168ea917fdbf98c27aa50787e296cae91effc。

## 目标

更新 MolecularNodes、GXNU-MolStudio、VTK 到本批固定的默认主干提交，分别记录最近实际参考版本、完整提交范围和适用性。历史研究保留原身份。研究使用 GPT-6.1 Sol high；产品实现可使用 GPT-6 Astra high，各自在 .worktrees 下独立分支工作，主 Agent 串行更新分支、复验、ff-only 合并 main。

## 已批准功能

1. 标量场/电荷材质增加明确应用的 QC_DEFAULT、Viridis、Cividis 色带预设。默认三个色阶保持现状；两新预设保留 MolecularNodes 2eb05987d0fa60678ea2d793c95fe4bc886270af 中全部 13 个色阶与插值。确认才修改，取消不修改，支持 Undo/Redo；保留范围、反转、透明度、图例、科学数组。目标缺失、重复、只读或对话框期间变更时拒绝并保持原状态。共享材质沿用原生同步语义且对话框说明。不扩展 fog。现有实际色带摘要足够，不新增 Dataset schema。
2. 真实 Geometry Nodes 过滤后逐点验证 qc_atom_id、位置、元素和电荷对应；补实际缺失的有效域/颜色/图例/剖面/CSV覆盖。只有发现真实缺陷才修产品。
3. 原子数、键数、三种现有样式和 Quality 的分阶段性能基准，记录环境、输入/源码身份、冷热条件、创建/节点求值/网格提取耗时与内存。工程合成数据不作为科学接受证据，不预承诺优化。
4. 通过验证后补公开多 Cube 叠加教程、色带操作、源原子与求值几何/缺失属性边界，更新相关用户和技术文档、研究索引、CHANGELOG、ARTIFACTS。

## 边界

参考代码不作为新增运行依赖；保留单扩展、Blender 5.1.1、0.1.0 Alpha 和现有锁定 wheels。IRC逐步电荷因P04/C10无真实部分电荷输入暂缓；DI/ASM/ESM等新科学分析只记录候选。本地提交、工作树与分支归档已授权；不push或发布。保留主检出已有两张截图与未命名.blend，不覆盖用户工程。

## 验收

合并后的 main 构建 ZIP 并记录源码提交、产品树、SHA-256和安装身份；隔离环境先运行科学/相关单测、节点及安装检查，再串行执行实际GUI应用/取消/反转/Undo/Redo、共享/复制、科学数据不变、图例/导出和多Cube测试，保存及原地/中文移动冷重开。主 Agent 一次只操作一个 Blender 进程。隔离通过后更新用户日常安装并运行科学运行环境与新增入口烟测。更新当前安装入口与Passed/Failed/Not Run证据；独立人工/科研接受不代签。功能变更后的GUI必须复验，旧登记仅供定位。文档阶段若改变产品代码需重建复验。
