# QCBlender 0.0.1 操作指南

适用 Windows x64、Blender 5.1.1。此版本为本地验收候选，支持范围见 [验收记录](VALIDATION.md)。安装包包含解析及求值依赖，可断网安装和运行。

## 操作入口与对象选择

以下使用插件实际绘制的按钮文字。`N 侧栏` 指 3D Viewport → N → QCBlender；`对象属性` 指 Properties → Object → **QCBlender · 对象与量子化学**。多数子面板默认折叠，需要展开。先切换物体模式并选中对应 QC 对象；按钮灰显时查看其下方原因。对象属性固定了其他对象时，先解除固定或改为当前对象。

| 操作 | 需要选中的对象 | 编辑器与面板路径 | 可见按钮或控件 |
| --- | --- | --- | --- |
| 导入计算结果 | 无 | N 侧栏 → 工作流 | 导入 Gaussian / Cube |
| 生成 MO、密度或 ESP | 含轨道的 FCHK 原子视图 | N 侧栏 → 工作流 | 生成量子化学场 |
| 查看能量、选择振动模式 | 含相应记录的原子视图 | 对象属性 → 科学记录与振动模式 | 能量列表、模式列表 |
| 振动显示参数 | 已选模式的原子视图 | 对象属性 → 高级参数 | Animate、Amplitude (angstrom)、Phase、Cycles per second |
| 原子电荷着色 | 含电荷记录且未绑定着色场的原子视图 | 对象属性 → 科学记录与振动模式 | 设置原子电荷着色 |
| 创建偶极 | 含偶极记录的原子视图 | N 侧栏 → 创建视图与检查工具 | 创建偶极矢量 |
| 声明 Cube 量与单位 | unknown_scalar 场视图 | 对象属性的 QCBlender 主面板 | 声明 Cube 物理量与单位 |
| 绑定或替换着色场 | 要着色的几何视图 | 对象属性 → 颜色映射 | 选择／替换着色场 |
| 创建切片、等值面或体积雾 | 有关联体场的标量视图 | N 侧栏 → 创建视图与检查工具 | 创建切片、创建等值面层、创建体积雾 |
| 创建线剖面 | 有关联体场的场视图或切片 | N 侧栏 → 创建视图与检查工具 | 记录剖面起点、创建线剖面 |
| 导出剖面 | 剖面曲线 | N 侧栏 → 创建视图与检查工具 | 导出剖面 CSV |
| 局部选择、氢显隐 | 原子视图 | 对象属性 → 局部选择与标注 | 设置局部选择、隐藏氢等 |
| 创建标注、优化视图 | 原子视图；优化需有逐步数据 | N 侧栏 → 创建视图与检查工具 | 创建编号／距离／角度／二面角标注、创建优化轨迹视图 |
| 查看来源 | 对应 QC 视图 | 对象属性的 QCBlender 主面板 | 来源详情、刷新来源、关联选中数据源 |
| 浏览外部结果 | 对应外部结果显示层 | 对象属性 → External Result Browser | 应用筛选、更新散点 |
| 管理显示层 | 对应 QC 显示层 | N 侧栏 → Display Layers | 显隐、复制、排序、删除图标；查看对象属性 |
| 复制显示参数 | 多选同类 QC 视图，最后选参数来源 | 3D Viewport → 对象右键菜单 → QCBlender | 复制显示参数到选中视图 |
| 创建相机 | 选中需要出图的 QC 视图 | N 侧栏 → 创建视图与检查工具 | 创建取景相机 |
| 保存与归档 | 已打开的 QC 工程 | N 侧栏 → 工程与诊断 | 保存自包含工程、归档工程 |
| 恢复显示缓存或数据路径 | 受影响的 QC 视图 | N 侧栏 → 工程与诊断 | 重建显示缓存、重新定位数据 |

对话框、属性和部分专项面板仍使用英文名称；以表中入口进入后再调整这些控件。后文括号中的英文操作名称仅辅助辨认搜索或日志，不代表侧栏按钮文字。

## 安装与首次导入

1. 在 Blender Preferences → Get Extensions 的菜单中选择 **Install from Disk**，安装已取得且完成资格检查的 QCBlender 扩展 ZIP 并启用。获取状态见 [README](../README.md)，开发者构建见 [DEVELOPMENT](DEVELOPMENT.md)。
2. 在 Add-ons 中展开 QCBlender，可用 **Check Scientific Runtime** 检查随包组件。
3. 在 3D Viewport 按 N 打开侧栏，选择 **QCBlender → 工作流 → 导入 Gaussian / Cube**。导入 `.fchk/.fch`、`.cube/.cub` 或 Gaussian `.log/.out`。
4. Log/Out 导入先异步显示 **Choose Gaussian Calculation**。选择计算段，核对 route、终止状态、原文行区间、能量和显式几何提示，再确认导入；取消不会创建科学 Dataset 或场景对象。预览后源文件改变时须重新预览。优化后频率计算通常属于另一个 Link1 job，应选择包含频率的段；缺少显式几何时不从其他段继承。脚本/MCP 的 `job_number` 仍从 1 开始，worker 的 `job_index` 从 0 开始。导入后提供独立逐步视图，见下文；外部 IRC FCHK 序列入口见[导入说明](EXTERNAL_ANALYSIS_IMPORT.md)。

坐标统一为 Å，1 Blender 单位表示 1 Å。原子之间的连线由元素半径和距离推断，不代表计算所得键级。原始电荷、坐标、轨道和场保存在科学数据中；对象移动和节点样式不会修改它们。

`.chk` 不能直接读取。在已有 Gaussian 的机器上执行 `formchk calculation.chk calculation.fchk`，再导入生成的 FCHK。本扩展不提供 Gaussian 可执行文件。

## 轨道、电子密度与 ESP

选择 FCHK 原子对象，在 **N 侧栏 → 工作流** 点击 **生成量子化学场**。选择 Molecular orbital、Electron density、Alpha/Beta density、Spin density 或 Electrostatic potential。

MO 可按 Alpha/Beta 通道选择 HOMO、LUMO 或从 1 开始的源编号；对话框显示占据数和轨道能量。HOMO/LUMO 按该通道的真实占据和能量选择，缺少能量时使用明确源编号。简并子空间的轨道形状不唯一，不能仅凭图形不同断言计算不同。

网格间距与边缘宽度使用 Å。建议先用默认 0.2 Å 间距预览，再同时检查更细间距和更大空间范围。Memory budget 约束数值数组估计，不是整个 Blender 进程的硬内存上限。大网格，尤其 ESP，可能耗时较长；侧栏显示阶段和进度，Esc 取消当前操作。

生成后，在对象属性的 **几何表示** 调整 **正值阈值**（Isovalue）及 MO 的 **显示正相位／显示负相位**（Positive/Negative Phase），分别控制蓝色正面和红色负面；**Smooth Normals** 只改变法线着色。这些控件与 Geometry Nodes 修改器共享参数。阈值、颜色和法线调整不重新求值；改变 MO 或网格需要重新生成场。

| 量 | 数值单位 |
| --- | --- |
| MO 振幅 | bohr^-3/2 |
| 总/Alpha/Beta/自旋电子数密度 | electron/bohr^3 |
| ESP | hartree/e |
| 轨道和电子总能量 | Hartree |

ESP 来自核与电子密度库仑势；距核小于 0.02 bohr 的点标为无效。无效掩码不是物理零值。振动仅移动分子显示，静态 MO/密度不随之变形成时变波函数。

## Cube、双场颜色和切片

多 MO Cube 保留各数据集编号。普通 Cube 的数值类型不能仅从文件名或注释确定，因此初始显示 `unknown_scalar` / `unknown`。核对生成程序和单位后，选场视图，在对象属性主面板点击 **声明 Cube 物理量与单位**，显式声明物理量及其已有原子单位；操作记录为用户标注，**不换算数值**。其他单位的场须先正确转换。

生成同一 FCHK 的电子密度和 ESP 后，选中密度表面，在 **对象属性 → 颜色映射 → 选择／替换着色场** 选择 ESP。密度定义表面形状，ESP 定义颜色；隐藏 ESP 表面即可保留单个成图表面。不要删除其隐藏的 volume 数据对象。原有多选操作仍可通过 F3 搜索 **Map Selected Field to Active Surface**：先选 ESP 表面，再 Shift 选密度表面，使密度成为活动对象。

**Color Minimum / Center / Maximum** 应严格递增。默认红→白→蓝，中心对应白色；**Show Legend** 和 **Legend Position** 控制与实际范围联动的图例。紫红色表示采样超出有效域。原生材质可继续编辑；为科学比较应记录范围、颜色方案和 Blender 的色彩管理设置。

选中几何视图后点击 **选择／替换着色场**，直接选择场来源。候选显示源文件、摘要、计算段、场量和轨道；首次绑定设置范围，替换保留当前范围与图例位置。活动视图的数据来源分组显示几何场，**来源详情** 可分别核对几何与着色来源。原有多选着色的选择顺序见本节前文。同一原子视图使用电荷着色或网格场着色中的一种；需同时比较时，从原始原子视图分别创建独立显示层。

**零中心对称** 输入正数 R 后设置 `−R / 0 / +R`。**读取有效范围** 异步读取当前绑定色场的全部有效格点：跨零时中心为零，否则为中点；Esc 取消。常量场、没有有效点或任务中来源/范围改变时保留原值。读取只执行一次，后续调整阈值不会自动缩放色标。范围外数值使用端点颜色，无效采样使用洋红色。体积雾继续使用自身的两点色标控件。

选择场视图，在 **N 侧栏 → 创建视图与检查工具** 点击 **创建切片**，可调中心、旋转、尺寸和分辨率。场坐标及对象相对变换由节点处理。整体移动数据及其视图时优先移动原子父对象。

切片的对象属性提供“切片等值线”：默认关闭，开启后按当前颜色范围生成九级等值线，也可输入最多 64 个显式阈值。可选择几何场或已绑定色场；两者不同时，几何场需要显式阈值。更改平面或阈值后异步更新，期间隐藏旧曲线与标签。无效采样单元不连线。颜色预设在材质属性中选择，细节可继续编辑原生材质节点。

两个来源需先检查原子顺序和构型。选两个原子对象，最后选参考对象，在对象属性主面板点击 **关联选中数据源**；需要时启用刚体旋转/平移。线性或单中心结构无法唯一确定轨道方向，因此不自动刚体配准。关联保留各来源自己的能量和性质，不据几何相同推断理论层次相同。

## 场值线剖面与 CSV

选中场视图或切片，将 3D 游标放到起点，在 **N 侧栏 → 创建视图与检查工具** 点击 **记录剖面起点**；保持同一视图为活动对象，移动游标到终点，再点 **创建线剖面**。默认采几何场；已绑定可核对的颜色场时可显式选 Color。默认 101 点，可设 2–1001 点，包含端点。距离按所选字段源坐标计算，单位 Å；域外或无效点使曲线断开。没有相邻有效点时拒绝创建。

剖面对象属性的“剖面坐标轴与排版”可调整线性坐标范围、图幅、刻度、小数位数和线宽，再点击“应用排版”。图幅和线宽属于本地布局单位；这些操作不改变采样快照或 CSV。全局显示层的视口和渲染开关同时控制生成的曲线与标签，并保留各标签原有的独立显隐选择。

生成的独立曲线是采样快照，在 N 侧栏的 **Display Layers** 可复制、显隐、排序；移动只影响排版。侧栏显示单位与有效点数，对象属性的 **来源详情** 可查看原字段、完整来源摘要和采样条件。选中剖面曲线，在 **N 侧栏 → 创建视图与检查工具 → 导出剖面 CSV** 从保存数组导出距离、坐标、值、单位及 valid；无效值留空。保存和移动工程后仍可重导 CSV；外部 CSV 单独保存。

## 电荷、偶极、能量和振动

选中原子视图，在 **对象属性 → 科学记录与振动模式 → 设置原子电荷着色** 选择实际读到的布居方法；电荷值以电子电荷单位显示。在 **N 侧栏 → 创建视图与检查工具 → 创建偶极矢量** 显示物理偶极矢量，节点的 Angstrom per Debye 仅为箭头显示比例。源编号测量见下文的标注操作；不测动画瞬时距离。

选中含能量记录的原子视图，展开 **对象属性 → 科学记录与振动模式** 的能量列表，选择记录后查看 Hartree 值、方法和类型；列表保留来源位置和角色。MP2、CCSD(T)、DSDPBEP86、具备明确选态标记的 TD 输出分别保留目标值与参考 SCF；热校正、ZPE、焓和自由能单列。只有正常终止且目标唯一时自动选择。多个计算步、正文/archive 冲突或尚未验证的方法显示候选/诊断，不自动选最后一条 SCF。

频率 job 导入后选中原子视图，在 **对象属性 → 科学记录与振动模式** 的模式列表选择模式，IR 棒状图同步突出显示。在同级 **高级参数** 中，**Animate** 开启动画，**Amplitude (angstrom)** 控制最大原子显示位移，**Phase** 控制相位，**Cycles per second** 控制播放速度；勾选 Animate 后在时间轴播放才看到逐帧运动。位移来自真实正常模式；每个模式统一归一化到最大原子位移为 1 后供显示。播放速度不是物理振动频率，源频率始终以 cm^-1 保留。**几何表示 → Show Displacement Vectors** 显示位移方向/幅度；负频率标注 imaginary。

## Gaussian 优化轨迹浏览

导入含 `Opt` 的 Log/Out 并选择计算段。选中原子视图，在 **N 侧栏 → 创建视图与检查工具 → 创建优化轨迹视图** 创建位于原视图旁边的独立视图；对象属性的 **Optimization Trajectory → Create Optimization View** 也提供入口。选中新视图，在该面板通过 **Previous / Next / Choose Step** 切换，查看步号、该步能量、计算终止状态、收敛数值/阈值及原文位置。**来源详情 → Optimization step** 保留当前步的完整记录。

坐标为 Å，能量为 Hartree；收敛表保留 Gaussian 打印的内部单位声明，不按显示坐标单位换算。缺失或歧义能量明确显示状态；失败或截断日志只能浏览具有明确步号和构型的已有记录。扫描、重启、QST2/QST3 和复合路径当前显示不可用及原因；普通导入仍保留原行为。

优化步是离散迭代，不代表物理时间。轨迹视图不携带最终构型的电荷、偶极、振动或空间场，原视图保留这些已核实的属性。默认空间填充显示；若改用球棍，键连接是第 1 步推断的固定显示连接，不是逐步键级。复制后可独立切步，保存和搬移方式与其他 QC 工程相同。旧工程没有逐步数组时，需要从原始 Log/Out 重新导入。

## 原子选择与场景标注

在 **对象属性 → 局部选择与标注 → 设置局部选择** 输入 `1,3,7-10`，或按种子原子和 Å 半径建立邻域，可替换、并集、交集、差集和反选。局部集合与元素、连续编号及氢显隐共同作用。集合在优化/IRC 换步后保持固定；需要更新时点击 **按当前步重新计算**。在 **N 侧栏 → 创建视图与检查工具 → 创建局部显示层** 生成可独立调整样式和材质的副本；IRC 仅支持原位选择。**清除局部限制** 恢复由其他筛选条件控制的显示。

选中原子视图，在 **N 侧栏 → 创建视图与检查工具** 点击 **创建编号标注／创建距离标注／创建角度标注／创建二面角标注**；对象属性的 **局部选择与标注 → Source Atom Annotations** 也提供 Atoms、Distance、Angle、Dihedral 按钮。按测量顺序填写源编号；距离为 Å，角度为度，二面角按 A–B–C–D 的 B→C 轴使用带符号 atan2，范围 `(-180°,180°]`。测量读取真实源构型或当前优化/IRC 步，忽略对象缩放和振动展示位移；换步会同步文字、步号和锚点，退化时显示 undefined 及原因。

标注是可保存的场景文字与引线，可调整字号、颜色、三维偏移、小数位、引线宽度和显隐；布局尺寸属于视图本地场景单位。**Face All to Camera** 一次性朝向当前相机。通过显示层复制/删除时标注一起处理；副本可独立编辑。选中标注后可继续编辑并查看所属视图的来源详情。

## 相机、渲染与图注

选中需要出图的 QC 视图，在 3D 视口调整观察方向后，点击 **N 侧栏 → 创建视图与检查工具 → 创建取景相机**。它新建并激活正交相机，按当前帧的求值边界、渲染宽高比和默认每侧 5% 留白取景；操作后可在原生调整面板修改 Margin。已有相机、灯光和对象变换保留。渲染隐藏对象及内部数据源不参与；空几何、无有效选择或修改器视口/渲染开关不一致时给出错误。

设置 Blender 相机、灯光和输出后，使用原生 **Render Image** 或 **Render Animation**。推荐动画输出 PNG 序列，保留项目作为可编辑来源。图注应记录计算方法/基组、源文件摘要、场量/单位、MO 编号和自旋、网格/等值、色标；振动另记模式频率、显示振幅和非物理播放速度。这些值分别在侧栏、对象属性、修改器和 `.qcdata` manifest 中保存。

## 显示层与来源记录

N 侧栏的 **Display Layers** 按源文件 SHA-256 和计算段分组。选择显示层后，在对象属性主面板点击 **来源详情**，通过 **Source record** 分别查看几何来源、计算段、场量及单位、着色来源和外部分析关联。详情只读；计算段编号从 1 开始，完整摘要用于区分同名文件。IR 谱图和偶极沿其父原子对象读取来源。

对象属性主面板的 **刷新来源** 按需刷新关联数据的 metadata。旧工程刷新前可能显示“未记录”并保守分组；没有记录的信息不作推断，缺失或损坏的关联显示错误。刷新与查看详情不加载科学数组；显示层的复制、显隐、排序和节点编辑继续使用原有操作。

## 外部结果筛选与浏览

外部结果的显示筛选在对象属性 **External Result Browser** 中设置，点击 **应用筛选** 或 **更新散点** 后生效。ESP 极值和 AIM 临界点按活动显示层的类型浏览，源编号 `0` 表示该类型的全部记录；可按已有数值筛选、定位和突出显示，标签显示源编号及记录值。切换类型请选择对应显示层，筛选不改写其他显示层。面积分布按中心值或已记录区间选择完整区间，显示原始总面积、所选小计和原表百分比，不重新归一化。

IGMH／IRI 散点默认横轴为着色场、纵轴为几何场；可交换轴并分别启用上下界。操作先筛选全部有效样本，再确定性显示最多 50,000 点，同时报告匹配总数与显示数。NBO 可按编号、类型、占据数、供受体和 E(2) 浏览排序；ETS-NOCV 按 pair、自旋、特征值及能量浏览，并只定位来源关联唯一匹配的已有场视图。所有筛选保留原始记录、源编号和科学数组。

## 编辑器、显示参数与图例

N 侧栏提供数值摘要、导入导出、创建对象及全局显示层管理。选中 QC 对象后，在对象属性的 QCBlender 分组中调整科学数值、几何表示、颜色范围、空间观察和局部选择；可固定 Properties 对象以持续查看同一个视图。无关功能隐藏，缺少条件的操作灰显并说明原因。

材质属性的 QCBlender 分组提供默认材质、颜色、透明度和粗糙度入口，材质节点可在着色编辑器中继续修改。渲染器、画幅和色彩管理使用 Blender 原生设置。Geometry Nodes 保留实际显示流程和参数来源。

样式可直接选实体、线框、点或球棍、空间填充、键；阈值带字段单位，半径为 Å。MO 显示正相／负相，其他场显示正值／负值。源网格间距与显示几何精细度分别展示。资产浏览器选择 **QCBlender Nodes**，可按数据与采样、原子选择、表示、颜色映射及空间分类查找九个通用节点；工程内绑定 Dataset 的节点组继续内部使用。

多选同类 QC 视图，最后选择参数来源作为活动视图，在 **3D Viewport → 对象右键菜单 → QCBlender** 点击 **复制显示参数到选中视图**。可分别勾选几何表示、外观、数值设置。执行前检查所有目标；阈值和色标范围要求对应字段的量名、单位已知且一致，电荷范围还要求同一布居方法。不兼容时可明确取消数值设置，仅复制外观或几何。目标的数据、轨道、原子选择、位置、裁剪和图例位置保留；复制后的材质与色带可独立编辑，支持撤销、重做与配套工程保存。无法识别的自定义图给出错误。

对象属性的 **图例排版** 可调整长度、宽度、字号、小数位数、横竖方向、旋转和位置，尺寸属于布局单位。默认值为长度 2、宽度 0.18、字号 0.16、五位小数、横向；三个数值与色带读取当前映射，量名和单位来自绑定字段。布局按视图独立保存，**复制显示参数到选中视图** 保留目标的图例布局。已知旧版图例可通过升级按钮取得新控件；无法识别的自定义图保持原状并提示原因。

## 保存、移动与工程归档

在 **N 侧栏 → 工程与诊断 → 保存自包含工程** 保存 `.blend` 和同名 `.qcdata/`（操作名 Save Portable QC Project）。两者必须一起移动。`.qcdata` 包含数值数组、来源/单位和可重建的 VDB 显示缓存；`.blend` 保存节点、材质、选择和动画设置。

同一面板的 **归档工程**（Package QC Project）打包磁盘上最近保存的工程；先保存最新修改，再打包。接收者解压整个 ZIP 后打开 `.blend`。仅使用 Blender 默认保存，可能仍引用扩展任务目录；正式交付前使用 QCBlender 的配套保存。

缺少 VDB 时选择受影响对象，使用同一面板的 **重建显示缓存**（Rebuild Volume Cache）；若整个数据目录移动，使用 **重新定位数据**（Relocate Scientific Dataset）选择相同数据集的 `manifest.json`，内容摘要必须匹配。科学数组丢失时无法从表面网格恢复波函数。

缓存位于此扩展的用户数据目录 `jobs/`。当前不自动清理。清理前保存所有需要的配套工程、确认无正在运行的 QC 任务，再处理不再需要的任务目录；不在使用中卸载或移动其文件。
