# QCBlender 0.1.0 Alpha Preview

Windows x64 · Blender 5.1.1. The manifest allows Blender ≥ 5.1.1 and < 5.2.0. This prerelease is for trying the documented workflows; independent human/scientific acceptance remains pending.

Download `qcblender-0.1.0.zip` for the self-contained extension and `qcblender-tutorial-0.1.0.zip` for the Chinese SOP, all 12 topics, screenshots, renders and required public inputs. The tutorial does not include a second installer. Compare the downloaded files with `SHA256SUMS.txt`; `release-manifest.json` records their sizes, hashes and candidate source/run identity. Source archives generated by GitHub are not extension installers.

For ZIP installation, open **Edit → Preferences → Get Extensions → menu → Install from Disk**, select the extension ZIP, then confirm QCBlender is enabled under **Add-ons**.

For remote installation:

1. Enable **Edit → Preferences → System → Network → Allow Online Access**.
2. Open **Get Extensions → Repositories → ＋ → Add Remote Repository** and paste `https://notes.psiqaq.cn/QCBlender/index.json`.
3. Sync, search for **QCBlender**, install and enable it. Run **Check Scientific Runtime** before starting P01.

The public repository index becomes available after the Release's Pages deployment finishes. If synchronization fails, check online access and the complete URL, or use the ZIP installer.

## 中文安装说明

本预览版仅覆盖 Windows x64、Blender 5.1.1。扩展声明范围为 Blender ≥ 5.1.1、< 5.2.0；独立人工及科研验收仍待完成。

下载扩展 ZIP 与完整教程 ZIP，先核对同页 SHA-256。教程解压后保留 `human/`、`shared/` 的相对位置，不需要额外安装 Python 科学库。

- **ZIP 安装**：编辑 → 偏好设置 → 获取扩展 → 菜单 → 从磁盘安装，选择 `qcblender-0.1.0.zip`。
- **远程仓库安装**：先在 Edit → Preferences → System → Network 启用 Allow Online Access；再进入 Get Extensions → Repositories → ＋ → Add Remote Repository，粘贴完整地址 `https://notes.psiqaq.cn/QCBlender/index.json`。同步后搜索并安装 QCBlender。
- **安装后**：在 Add-ons 中确认启用，运行 Check Scientific Runtime，再从教程的 P01 轨道案例开始。

其他平台、ECP、复轨道、周期体系、ORCA 原生格式与 `.mwfn` 不在本次支持范围。QCBlender 读取已有结果并求值网格，不执行新的 SCF 计算。使用或分发教程素材时保留各文件的许可、来源及软件引用。
