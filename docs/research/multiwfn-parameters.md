## 与本轮界面直接相关的输出

| 输出/参数 | 一手证据 | QCBlender 处理含义 |
| --- | --- | --- |
| 切片、等值线、色谱 | 手册 §3.5.2–3.5.4，PDF p.87–91；`0123dim.f90:609–623,1597–1648,1865–1867,2888–2971` | Multiwfn 区分平面网格/位置、色阶范围、等值线阈值、线宽及标签。QCBlender 的切片网格采样、等值线数值和视觉排版应分别保存；线宽/标签不改变源科学数组。`9` 条内部线和 `64` 条上限是 QC 规格，不是 Multiwfn 默认值。 |
| IGMH 双场与散点轴 | 手册 §3.23.6，PDF p.327–328；§4.20.11，PDF p.901–904；`visweak.f90:470–483,640–719` | 源码将 `sign(lambda2)rho` 作为散点横轴、`delta-g_inter`（或其他显式选择的 delta-g 分量）作为纵轴，并分别导出 `sl2r.cub` 和 `dg_inter.cub`；`output.txt` 的列序为 inter、intra、total、sl2r。需要保存几何场/色场角色与轴量名，不能仅凭两个 Cube 文件名互换用途。源码轴标把两量都写为 `a.u.`，但二者物理定义不同；不能合并成一个通用的 `dimensionless` 默认值。 |
| IRI 定义与指数 | 手册 §3.23.8，PDF p.329–330；§4.20.4，PDF p.879–880；`function.f90:5148–5157`、`define.f90:489`、`fileIO.f90:7703–7735` | 源码用 `|grad rho| / rho^p`，其中 `uservar=0` 时 `p=1.1`；低密度截断 `IRI_rhocut` 默认 `5e-5`，相应点被赋值 `5`。通用 Cube 写出头只记录生成器和格点数，不记录指数、截断或物理量单位；独立导入时缺失者应显示未记录并要求来源声明，不静默写入源码默认值。 |
| ESP 表面极值文本 | 手册 §4.12.1，PDF p.689–696；`surfana.f90:1395–1437` | `surfanalysis.txt` 保留最小/最大分类与原编号。ESP 类输出表列出 a.u.、eV、kcal/mol 和 Å 坐标；其他映射函数可以只有数值和 Å 坐标。筛选、定位和高亮须保留源编号、极值类型及所选单位。 |
| ESP 表面极值 PDB | 手册 §4.12.1，PDF p.689–696；`surfana.f90:1339–1343,1446–1499` | ESP 写入 PDB B-factor 时依范围使用 `kcal/mol` 或 `eV`，并在 `REMARK` 写明单位；最大值用 C、最小值用 O 的伪原子表达。读取时应先记录原始 `REMARK` 及位置，显式用户单位冲突应拒绝，无声明时请用户指定；不得把元素字母当作真实原子。PDB 序号与文本中同类局部序号分别核对。 |
| 面积分箱 | 手册 §4.12.1，PDF p.689–696；`surfana.f90:1749–1778` | 原程序先指定映射值范围、分箱数和可选能量单位，再打印 `Begin / End / Center / Area / %`，面积为 Å²；区间按左闭右开统计，百分比相对于全部表面积 `surfareaall`。QC 的五列输入应保留五列；三列资料缺失的上下界不能用中心点推回。显示筛选后的小计应与原百分比总计区分。 |
| AIM 临界点 | 手册 §3.14.2，PDF p.184 起；`topology.f90:460–479,621–639,1474–1506` | `CPprop.txt` 明写 CP 序号、类型与 Bohr/Å 坐标；`CPs.pdb` 把序号写入 HETATM serial，并用 C/N/O/F 表示四种 CP 类型。筛选按源编号/类型/已记录值执行；伪元素不是原子化学元素，定位不得改写来源记录。 |
| NOCV 对与能量 | 手册 §3.26.2–3.26.3，PDF p.353–356；§4.23.1，PDF p.943–945；`ETS_NOCV.f90:293–296,339–361,812–873` | 输出按 pair 与轨道编号组织，阈值会隐藏小本征值项；开壳层分 Alpha/Beta，能量单位 `kcal/mol`。未取得 Fock/KS 矩阵时程序把轨道能量置零并明确声明“未计算”，所以全零值本身不能代替状态判断。浏览与定位应以源 pair、spin、轨道身份和有无计算声明约束。 |
| NBO 信息 | 手册 §4.0.2，PDF p.459 起；`NAONBO.f90:3–88`、`fileIO.f90:652–653` | Multiwfn 可读取 NBO 程序输出并显示轨道；某些 `saveNBO` 路径会把自动推定或占位的占据数清零。QCBlender 对 NBO 编号、类型、占据及供受体/E(2) 只浏览已有原始记录；不能把零占据或缺少 E(2) 推断为真实科学结论。 |

上述来源只支撑输出语义与界面字段选择。能力判断、点选坐标变换、抽样上限、异步身份核对、Undo 和资产库分类属于 QCBlender 自身设计，需用本轮实现及真实工程另行验收。

## QCBlender 原生界面分工

`qcblender/blender/editor_ui.py` 将 N-Panel 用于数据集摘要、导入与创建视图、全局显示层及工程操作；持久的科学记录和视图参数进入 Object Properties。对象子面板按几何表示、颜色映射、图例排版、空间观察、高级参数及局部选择显示相关控件，并依活动对象与可用数据决定入口。Material Properties 提供材质参数和着色器节点编辑入口；默认材质节点可独立修改。渲染与输出继续使用 Blender 的 Render、Output 和 Color Management 原生面板。

`qcblender/blender/ui.py` 从现有 Geometry Nodes 输入读取并编辑显示值；界面分组不另存第二套数值。源场的量名、单位、坐标、编号、计算状态和文件摘要属于科学记录，筛选、色谱、等值线、标签与排版属于视图。界面重绘只读取已缓存元数据和当前节点值；重新解析文件、采样数组及完整科学校验留在用户触发的操作和后台任务。本段说明代码分工与设计边界，不能替代 Blender 实际入口、保存重开和视觉验收。
