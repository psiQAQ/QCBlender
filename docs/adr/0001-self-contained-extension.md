# 单个 Blender 扩展内完成量子化学数据处理

状态：accepted，2026-09-22，依据用户明确要求。

QCBlender 的导入、通用量子化学数据转换、波函数求值、保存与显示均由一个扩展提供。优先 Blender 自带能力，必要依赖随包 wheels；长任务可用同一 Blender 启动无界面子进程。cbq_core 仅作思想/代码参考，移植时记录版本和许可证。

此前方案提出外部 chemblender-prepare runtime 与 CBQ 模型。用户选择独立单扩展交付以减少配置步骤，因此项目承担 wheel 兼容构建、依赖冲突验证、插件内数据契约和任务生命周期的维护成本。科学代码仍与 bpy 分离。

用户确认首版内置波函数求值，覆盖非周期实值 HF/DFT（含开壳层/常见基组）；更广方法的能量读取独立于波函数求值能力。首发 Windows x64 + Blender 5.1.1，优化/IRC、差分、WFN/WFX、相关密度/多态求值和高级分析分期交付。
